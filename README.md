One funny line about office life: "HR emailed everyone to stop replying all, and forty people replied all to confirm they understood." It turns on a real detail of office life, the reply-all storm, and lands the laugh in the last few words: forty people replying all to confirm they understood the email telling them to stop replying all.

## Run it

```sh
node main.ts
```

`main.ts` writes the joke line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` by default), verifying first that it is a single line of 1–199 characters with no dash, no control characters, and no padding whitespace.
